# 知识图谱使用指南

这份文档教你:**怎么写笔记让知识自动连成网**、**AI 会帮你产出什么**、**图谱里的导航工具怎么用**。

---

## 一、入口与切换

打开"大脑/知识库"页面,顶部 Header 中间有切换:

- **工业图谱**(默认):新的高性能 3D 知识图谱。
- **经典视图**:旧版图谱(作为回退保留)。

首次进入工业图谱会自动建立图索引并渲染。下方状态条会显示"节点 N · 边 M"。

---

## 二、让知识连起来:双链与链接语法

你**不需要手动连线**。只要在 Markdown 笔记里用下面的写法,保存后关系就会自动进入图谱(显示为 `link` 关系边)。

### 1. 双链 `[[...]]`(推荐)

```markdown
深度学习依赖 [[反向传播]] 和 [[梯度下降]]。
参见 [[损失函数|loss function]]      ← 用 | 指定显示别名
详见 [[Transformer#自注意力]]        ← 用 # 指向目标笔记里的某个标题
```

- `[[笔记名]]`:链接到同名笔记文件(按文件名匹配,大小写不敏感)。
- `[[笔记名|别名]]`:`|` 前是目标,后是显示文字。
- `[[笔记名#标题]]`:链接到目标笔记内的某个标题(精确到章节节点)。
- `[[#标题]]`:链接到当前文件内的标题。

### 2. 标准 Markdown 链接

```markdown
请看 [相关笔记](concepts/attention.md) 或 [上一篇](../intro.md#背景)
```

- 只有指向 `.md/.markdown` 或无扩展名的本地路径才会成为关系边。
- 外部链接(`http://`…)、图片 `![]()`、`.pdf/.png` 等资源会被忽略。

### 3. 标签 `#标签`

```markdown
这段讲卷积网络。 #深度学习/CNN #计算机视觉
```

- 行内 `#标签`(`#` 后紧跟非空白字符)会成为该段落/章节的分类标签。
- 标题行的 `#`、代码块里的 `#`、纯数字 `#123` 不会被当作标签。
- 支持层级标签 `#父/子`,支持中文。

> 小结:**养成写 `[[]]` 双链 + `#标签` 的习惯**,你的知识网络会自动生长,完全不用手动维护关系。

## 三、AI 会帮你产出什么

工具栏上有三个 AI 相关按钮,产出会**固化进图谱并在重建时保留**:

### 1. 「向量」—— 生成语义向量
点击后为所有章节/段落/文件/概念计算 embedding(首次会**自动下载**模型,默认 bge-m3 约 634MB,中英文混合与专业术语质量最强;可在需要更轻量时切换为 e5-small 约 131MB)。
完成后即可使用:
- **关联推荐**:选中任意节点 → 面板「推荐关联」→ 列出语义最相近、但尚未连接的知识点,点 `＋` 即建立关系。
- **标签推荐**:选中节点 → 面板「推荐标签」→ 把库里已有标签智能传播到相似节点,点 `＋` 采纳。
- **语义搜索**:顶部搜索框输入一句话,按语义(而非关键词)跳到最相关节点。

### 2. 「概念」—— AI 抽取概念与关系
用本地大模型从笔记正文抽取**概念/实体**,以及概念之间的**有类型关系**(相关 / 前置 / 阐述 / 矛盾 / 部分-整体 / 相似)。
产出:
- 新的**概念节点**(红色),横跨多篇笔记 —— 同一个概念被多处提及会聚到一个节点。
- 概念↔概念的 typed 关系边,以及"文件提及概念"的 `mention` 边。

### 3. 「社区」—— 自动归纳分类
用 Louvain 算法把**强关联的知识点自动聚成社区并着色**。相同颜色 = 一个主题簇。这是"自动归纳"的可视化,帮你发现知识的天然分组。

## 四、视角:同一份知识,四种看法

顶部下拉切换,切换时节点会平滑动画过渡到新布局:

| 视角 | 看什么 | 布局 |
|---|---|---|
| **关系视角** | 知识间的连接结构 | 力导向,强关联靠拢 |
| **分类视角** | 按标签/社区分块 | 同类聚成簇,簇心环形分布 |
| **时间视角** | 知识增长脉络 | 按修改时间沿横轴排布 |
| **重要度视角** | 哪些是核心知识 | PageRank 越高越靠中心 |

## 五、导航工具:让图谱带你找,而不是你去翻

| 工具 | 操作 | 作用 |
|---|---|---|
| **搜索框** | 输入回车 | 语义/名称检索,相机飞到命中节点 |
| **点击节点** | 单击 | 选中并高亮其 1 跳邻居(ego 网络),其余变暗;右侧出信息面板 |
| **聚焦邻居** | 面板按钮 | 重新聚光当前节点的邻居 |
| **路径** | 点「路径」后依次点两个节点 | 高亮两节点间的最短连接路径("这两块知识怎么连起来的") |
| **下钻** | 双击目录节点 | 进入该目录子图,面包屑可逐级返回 |
| **折叠** | 点「折叠」 | 按社区聚合成超级节点(总览);双击超级节点展开该社区 |
| **类型过滤** | 顶部复选框 | 按目录/文件/章节/段落/概念显隐 |
| **小地图** | 右下角,可点击 | 俯视全局;点击小地图把主视图相机移到对应位置 |
| **时间轴** | 底部滑块 / ▶ | 拖动按修改时间过滤;播放可回放知识随时间的增长 |

鼠标:左键旋转、右键平移、滚轮缩放。

## 六、推荐上手流程

1. 切到**工业图谱**,确认能看到带 `[[]]` 双链关系的图(关系视角)。
2. 想要语义能力 → 点**「向量」**(首次等模型下载),再选节点试「推荐关联/标签」。
3. 想要概念层 → 点**「概念」**让 AI 抽取(本地模型,稍慢)。
4. 想看主题分块 → 点**「社区」**着色,再切**分类视角**,或用**「折叠」**看主题总览。
5. 找特定知识 → 用**搜索框**;想知道两个知识怎么关联 → 用**「路径」**。

## 七、常见问题

- **图里没有关系边?** 说明笔记里还没用 `[[]]`/链接,或还没点「向量」「概念」。先补双链或跑 AI。
- **"推荐关联/标签"提示需要 embedding?** 先点一次**「向量」**。
- **改了笔记图没更新?** 文件变更会自动标脏,下次打开/点「重建」即刷新。
- **节点太多卡?** 用**「折叠」**看社区总览,或用类型过滤、下钻聚焦局部。
- **亮色主题下看不清?** 图谱已适配亮/暗色,会跟随应用主题自动切换。
